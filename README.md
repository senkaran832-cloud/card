## ⚙️ जानकारी कैसे बदलें? (`config.js`)

यदि आप कोई भी नाम, तारीख, समय या फोन नंबर बदलना चाहते हैं, तो आपको HTML या CSS बदलने की कोई आवश्यकता नहीं है।
बस **`config.js`** फ़ाइल को Notepad या किसी एडिटर में खोलें और मान बदल दें:

```javascript
// उदाहरण: दूल्हा-दुल्हन का नाम बदलना या क्रम बदलना
bride: {
  title: "आयुष्मती",
  name: "कृष्णा सेन",
  shortName: "कृष्णा",
  ...
},
groom: {
  title: "आयुष्मान",
  name: "आशीष सेन (बिद्द्)",
  shortName: "आशीष",
  ...
}
```

## 💻 अपने कंप्यूटर पर कैसे चलाएँ? (Run Locally)

### आसान तरीका (Direct Open):
1. इस फ़ोल्डर में मौजूद `index.html` फ़ाइल पर डबल-क्लिक करें।
2. यह आपके डिफ़ॉल्ट वेब ब्राउज़र (Chrome, Edge, Firefox) में तुरंत खुल जाएगा।

### लोकल सर्वर द्वारा (Local HTTP Server):
1. इस फ़ोल्डर में PowerShell या Command Prompt खोलें।
2. यह कमांड चलाएँ:
   ```bash
   python -m http.server 8080
   ```
3. अपने ब्राउज़र में खोलें:
   ```
   http://localhost:8080
   ```

## 🌐 इंटरनेट पर मुफ़्त में कैसे प्रकाशित करें? (Free Hosting)

आप इस वेबसाइट को बिना किसी खर्च के इंटरनेट पर लाइव कर सकते हैं:

### विकल्प १: Vercel या Netlify (सबसे आसान - ड्रैग और ड्रॉप)
1. [Netlify Drop](https://app.netlify.com/drop) पर जाएँ।
2. अपने इस पूरे `web page` फ़ोल्डर को वहाँ ड्रैग करके छोड़ दें।
3. कुछ ही सेकंडों में आपको मुफ़्त में एक लाइव वेबसाइट लिंक (URL) मिल जाएगा!

### विकल्प २: GitHub Pages
1. GitHub पर एक नया रिपॉजिटरी बनाएँ।
2. इन सभी फ़ाइलों को अपलोड करें।
3. रिपॉजिटरी की **Settings** > **Pages** में जाएँ।
4. Branch में `main` चुनकर Save करें। आपकी वेबसाइट लाइव हो जाएगी!
